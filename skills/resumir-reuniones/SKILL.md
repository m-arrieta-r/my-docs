# Resumir reuniones

## Cuándo usar

Cuando el usuario comparte la transcripción o las notas de una reunión y pide un resumen.

No lo uses para correos o documentos largos que no sean reuniones.

## Pasos

1. Identifica a los participantes.
2. Extrae las **decisiones** tomadas.
3. Lista los *pendientes* con su responsable y fecha, si se mencionan.
4. Termina con las preguntas abiertas.
